How-To

Do these steps in order. This guide is written for someone who has never done this before.

“Take it slow, follow the How-To tab, and you’ll be fine. Every button clicked once in the first go around.

Then when you go back into the app, just click on the Hermes tab, scroll down when it loads, and launch the dashboard and gateway, assuming they don’t do it automatically for you. Then click on ‘Open in browser’ to monitor chats and make sure Hermes is completing cycles, and go back to the app and click on Trading, which is modeled after the BH dashboard.

That’s it.”

—Matthew Knight, Founder, KnightTrader
Before you start — do not skip this
  1. You need a Windows 11 PC or a Mac.
  2. You need a debit card and the ability to open your bank app or use a chip reader.
  3. You need an email address and password you can remember.
  4. You need about 30–60 minutes of uninterrupted time.
  5. Turn off notifications or find a quiet screen so you can read each step.
If something fails, stop and read the exact message. Do not keep clicking randomly. Most failures are one missed field or one wrong network.
1
Join membership and save your login
You need an active membership to download and use the app. Use an email you can access and a password you can remember. You will use the same email and password in the app.
Click by click:
  1. On this site, click Join membership — $47/month.
  2. Enter your email and password.
  3. Complete Stripe checkout.
  4. Write your email and password down in a safe place on your computer or phone.
  5. Come back to this site, scroll to Login to download, enter the same email and password, then download.
Do not forget this password. You will need it every time you reinstall or sign into the app.
2
Install the app
Install like any normal program. There is nothing technical here.
Windows:
  1. Open the downloaded installer.
  2. Follow the prompts.
  3. When it finishes, find KnightTrader BloFin in your Start menu and open it.
Mac:
  1. Open the downloaded .dmg.
  2. Drag KnightTrader BloFin into your Applications folder.
  3. Open it from Applications.
  4. If macOS warns you, open System Settings → Privacy & Security and allow it.
If the app opens, you are good. If it closes immediately, read the error text and fix the first item it mentions.
What success looks like:
  1. You see the KnightTrader login screen or the How-To tab.
  2. The app stays open. It does not close by itself.
If it closes, take a screenshot of the error and fix that exact item before continuing.
3
Sign in to the app
Use the same email and password you used on the website.
  1. Type your email.
  2. Type your password.
  3. Click Sign in.
  4. If you see an error, check caps lock and retype both fields.
  5. If it says membership is not active, renew in the app Settings tab.
Do not guess passwords. If you forget it, click Forgot password?.
4
Keep this computer awake
If the computer sleeps, Hermes stops. Change these settings now so they do not surprise you later.
Windows 11 — exact clicks:
  1. Press the Windows key, type Settings, and open it.
  2. Click System.
  3. Click Power & battery.
  4. Click Screen and sleep.
  5. Set When plugged in, turn off my screen after to Never.
  6. Set When plugged in, put my device to sleep after to Never.
  7. If you see battery options, set them to Never or a long timeout.
  8. Close Settings.
Mac — exact clicks:
  1. Click the Apple menu → System Settings.
  2. Click Displays.
  3. Click Advanced or Options.
  4. Set Turn display off to Never or a long timeout.
  5. Click Battery.
  6. Click Options or Power Adapter.
  7. Set display and sleep timers to Never while plugged in.
  8. Close System Settings.
5
Install ProtonVPN and reach an allowed country
Use this only if Blofin is blocked in your country. Do not skip the wait times.
Exact routine:
  1. Go to protonvpn.com.
  2. Click Get Proton VPN or Download.
  3. Install the app.
  4. Create a free Proton account.
  5. Open ProtonVPN and click Connect.
  6. If it connects to the United States, leave it connected for now.
  7. Open the ProtonVPN app home screen.
  8. Click Change server.
  9. If the new country is not Romania, Poland, Netherlands, or Mexico, wait 1 minute 40 seconds.
  10. Click Change server again.
  11. If it is still not allowed, wait 1 minute 50 seconds.
  12. Click Change server a third time.
  13. If you are still not in an allowed country, click Disconnect, wait a moment, then click Connect.
  14. If it connects to the United States again, wait up to 10 minutes, then start again from step 7.
Allowed countries: Romania, Poland, Netherlands, Mexico. Not allowed: Singapore, United States, Canada.
6
Create your Nous Portal API key
Hermes needs this key to think and trade. After you sign up for Nous Portal, add at least $5 in credits. Then create the API key and paste it into the app.
Click by click:
  1. Open portal.nousresearch.com/manage-subscription.
  2. If you are not signed in, click Login.
  3. Open Plans if it is not already selected.
  4. Choose the Free $0 plan.
  5. Click Subscribe if prompted.
  6. Wait until the plan shows as active.
  7. Open Account → API keys or the API keys section in the portal.
  8. Click Create new API key.
  9. Copy the key immediately.
  10. Paste it into the app Setup tab in AI Credentials → Portal API Key.
After pasting, click Test AI Credentials in the app. If it says success, move on.
7
Create a Blofin account
This is the exchange where Hermes trades. Create the account first, before you buy crypto.
Click by click:
  1. Open blofin.com.
  2. Click Sign up or Get started.
  3. Enter your email and create a password.
  4. Verify your email if prompted.
  5. Enable security features such as two-factor authentication if prompted.
Keep this tab open. You will need Blofin open again when you create API keys and deposit funds.
8
Create Blofin API keys
The app needs three values: API Key, Secret Key, and Passphrase. The file loader can also read them from a text file.
Click by click:
  1. In Blofin, open your account menu and go to API Management or API.
  2. Click Create API key or New API key.
  3. Name the key something simple like KT Hermes.
  4. Enable Compendium permission.
  5. Enable Trading permission.
  6. Enable Transfer permission only if you plan to move funds inside Blofin.
  7. Save the key.
  8. Copy the API Key.
  9. Copy the Secret Key.
  10. Copy the Passphrase.
  11. Open the KnightTrader app Setup tab.
  12. Paste the API Key into API Key.
  13. Paste the Secret Key into Secret Key.
  14. Paste the Passphrase into Passphrase.
  15. If you saved the keys into a text file instead, click Load from file… and choose that file.
  16. Click Test Blofin Credentials.
  17. Wait for a success message before continuing.
If test fails: double-check the three values, then click test again. Do not move on until it succeeds.
9
Save credentials and write the compendium file
Saving writes the encrypted credentials locally. Writing the compendium creates the file Hermes reads.
  1. In the app Setup tab, click Save & Write Compendium.
  2. Wait for the success message.
  3. If you see an error, read it, fix it, then save again.
10
Create a Coinbase account
You will use Coinbase to turn debit-card money into crypto.
Click by click:
  1. Open coinbase.com in a browser.
  2. Click Get started.
  3. Enter your email.
  4. Create a password you can remember.
  5. Click the verification link Coinbase sends to your email.
  6. Add your phone number.
  7. Enable two-factor authentication.
  8. Verify your identity with a government-issued ID.
  9. Wait for approval if Coinbase asks for manual review.
Save your Coinbase email and password too.
11
Add your debit card to Coinbase
This is how you buy crypto with money from your bank.
  1. Open Coinbase and sign in.
  2. Click your profile picture or Settings.
  3. Click Payment methods.
  4. Click Add a payment method.
  5. Choose Debit card.
  6. Enter the card number, expiration date, and CVV.
  7. Enter the billing address exactly as your bank has it.
  8. Confirm the card.
  9. If Coinbase shows a small authorization hold, approve it in your bank app if needed.
If the card is declined, call your bank and allow online or card-not-present purchases.
12
Buy crypto with your debit card
Buy a small amount first. Card fees are higher than bank transfers.
  1. In Coinbase, click Trade or go to Buy.
  2. Choose USDC for your first buy. It is designed to stay near one dollar.
  3. Enter a small amount.
  4. Click Preview buy.
  5. Review the fee.
  6. Confirm the purchase.
  7. Wait until it says Completed.
If it fails, read the exact error. Usually it is the bank declining the card or card limits.
13
Get your Blofin deposit address
You will send crypto from Coinbase to this address. Do not skip this section.
Exact Blofin steps:
  1. Open blofin.com and sign in.
  2. Open Assets or Wallet.
  3. Click Deposit.
  4. Choose USDC if you bought USDC, or choose the exact coin you bought.
  5. Choose the network Coinbase will send on.
  6. Copy the deposit address.
  7. If Blofin asks for a memo or tag, copy that too.
Write down: coin, network, address, and memo if required.
14
Send crypto from Coinbase to Blofin
This is the most common place people lose funds. Do not rush. Match every field exactly.
Exact Coinbase steps:
  1. In Coinbase, open Portfolio or Assets.
  2. Find the coin you bought.
  3. Click Send.
  4. Paste the Blofin deposit address.
  5. If Coinbase asks for destination tag or memo, paste the Blofin memo here.
  6. Choose the network that matches Blofin exactly.
  7. Review the network fee.
  8. Click Continue or Preview.
  9. Confirm the send.
  10. Wait for the transaction to confirm.
If you send the wrong coin or wrong network, the funds may be lost. Double-check both before confirming.
After sending, open Blofin Assets and refresh until the deposit appears.
15
Add Defender exclusion on Windows before install
If you are on Windows, do this first. If you are on Mac, skip this step.
  1. In the app, go to the Hermes tab.
  2. Find Step 0: Whitelist in Windows Defender.
  3. Click Add Defender Exclusion.
  4. If a UAC window pops up, click Yes.
  5. If auto-add fails, open Windows Security → Virus & threat protection → Manage settings → Exclusions → Add folder.
  6. Add the folder shown in the app.
If you skip this, Hermes install may fail.
16
Install Hermes
This installs Hermes inside this app only.
  1. In the app Hermes tab, click Install Hermes.
  2. Wait for it to finish.
  3. If it says checking or installing, wait. Do not close the app.
  4. When it says installed, move to the next step.
17
Write compendium file again if needed
If you did not already click Save & Write Compendium in Setup, do it now.
  1. Open the app Setup tab.
  2. Confirm your Blofin keys are saved.
  3. Click Save & Write Compendium.
  4. Confirm it says written.
18
Start Hermes dashboard and gateway
The dashboard shows what Hermes is doing. The gateway is required for cron jobs.
  1. In the app Hermes tab, click Start Dashboard + Gateway.
  2. Wait for the status to change from Not running.
  3. Open Open in Browser if the embedded dashboard does not load.
  4. Confirm the dashboard opens at http://127.0.0.1:9119.
19
Auto-configure the trading cron
This tells Hermes to scan Blofin and trade every 10 minutes using market orders.
  1. In the app Hermes tab, click Auto-Configure Cron.
  2. If it succeeds, the cron is active.
  3. If auto-config is unavailable, copy the prompt shown.
  4. Open the Hermes dashboard in your browser.
  5. Paste the prompt into the assistant/cron setup area.
  6. Save the cron.
20
Confirm Hermes is actually trading
Do not assume it works. Verify these exact signals.
Checklist:
  1. Keep the computer awake using step 4.
  2. Open the app Trading tab.
  3. Confirm Trading dashboard updates.
  4. Confirm Last activity changes from Waiting for Hermes.
  5. Confirm Recent Activity shows a Hermes cron tick.
  6. If a trade happens, confirm Open positions appears.
  7. Open the app Logs tab.
  8. Look for successful cron activity.
  9. If nothing happens after a few minutes, open the Hermes dashboard in browser and inspect manually.
If the Trading tab webview is blank, use the Hermes dashboard in the browser. The browser dashboard is the source of truth.
What success looks like:
  1. Trading dashboard says Live · SSE connected or Live.
  2. Last activity says Signal connected or shows a recent timestamp.
  3. Recent Activity shows a line that says something like cron tick succeeded or a trade message.
  4. Open positions shows a position if a trade was placed.
  5. Equity number changes over time.
If any of these are missing, do not close the app. Open the Hermes dashboard in browser from the Hermes tab and check the assistant/cron logs there.
21
If something breaks, fix the first error message
Do not restart from the beginning. Read the exact message in Logs or on the button status, then fix that exact item.
Common fixes:
  1. Login fails: retype email and password. Check caps lock. Use Forgot password? if needed.
  2. Blofin test fails: double-check API Key, Secret Key, and Passphrase. Make sure you copied all three.
  3. Nous test fails: verify you selected a free model and pasted the exact Portal API key.
  4. VPN is U.S.: wait the full 1:40 or 1:50, then change server again. Do not rush.
  5. Dashboard blank: open Open in Browser from the Hermes tab. The browser dashboard is the source of truth.
  6. No trades yet: confirm Blofin has Futures/USDT-M balance, VPN is in an allowed country, and dashboard says gateway is running.
  7. Cron not firing: click Auto-Configure Cron again, or paste the prompt into the Hermes dashboard manually.
  8. Computer slept: reopen the app, confirm dashboard is still running, and check Logs.
If you are stuck for more than 10 minutes, stop and review the exact error text. The fix is almost always one field, one network, or one missed confirmation.
